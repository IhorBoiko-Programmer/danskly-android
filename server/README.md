# Danskly — сервер з ШІ

Це повна версія Danskly, яка працює на твоєму власному сайті, без Claude. ШІ-функції (тренер, перевірка текстів, приклади, нові слова) йдуть через OpenCode Go і модель DeepSeek V4.1 Flash.

## Як це влаштовано

```
Телефон друга ──► твій сайт на Cloudflare ──► OpenCode Go (DeepSeek)
                  (застосунок + сервер /api/ai,
                   ключі в зашифрованих секретах)
```

- **Ключі ніколи не потрапляють у браузер.** Вони лежать у зашифрованих секретах Cloudflare, і їх не видно навіть у панелі керування.
- **Фолбек.** Сервер пробує моделі по черзі (`AI_MODELS`), а для кожної моделі — усі ключі. Якщо ключ не відповів за 20 секунд, повернув помилку ліміту (429), помилку доступу (401/403) чи збій (5xx), сервер одразу бере наступний ключ. Якщо модель недоступна (400/404), він переходить до наступної моделі. Проблемний ключ на кілька хвилин відкладається в кінець черги.
- **Розподіл навантаження.** Запити по черзі розподіляються між усіма ключами.
- **Захист від чужого використання:** запити приймаються лише з твого сайту, діє обмеження частоти з однієї IP-адреси, обмежено довжину запиту й відповіді, а системна інструкція дозволяє моделі говорити лише про вивчення данської. За бажанням можна додати код доступу.

## Що потрібно

1. **Підписка OpenCode Go** і ключ API (opencode.ai → Console → Go).
2. **Регіон Global.** DeepSeek V4.1 Flash працює лише так: Console → Settings → Privacy → Regions → **Global**. Без цього ключ отримає відмову.
3. **Безкоштовний акаунт Cloudflare** (cloudflare.com).
4. **Node.js** (версія LTS з nodejs.org). Він потрібен лише на твоєму комп'ютері для розгортання.

## Розгортання: автоматично з GitHub

Сервер публікує GitHub Actions (`.github/workflows/android.yml`, крок **deploy**) після кожного пушу в `main`, якщо всі тести пройшли:

1. `node server/build.mjs` збирає `public/`: вебверсію з `web/index.html`, навчальні матеріали для Android (`content/*.json`) і `content/manifest.json` (версія матеріалів і найновіша збірка застосунку).
2. `wrangler deploy` публікує воркер.
3. Секрети `OPENCODE_KEYS` і (необов'язково) `ACCESS_CODE` переносяться з GitHub у зашифровані секрети Cloudflare.

Потрібні секрети репозиторію (Settings → Secrets and variables → Actions): `CLOUDFLARE_API_TOKEN` (шаблон «Edit Cloudflare Workers»), `CLOUDFLARE_ACCOUNT_ID`, `OPENCODE_KEYS`. Без них крок просто пропускається.

Адреса сервера — `https://danskly.<піддомен>.workers.dev`. Android-збірка бере її автоматично з акаунта Cloudflare (або зі змінної репозиторію `DANSKLY_AI_URL`).

### Автооновлення

- **Матеріали.** Застосунок під час запуску перевіряє `content/manifest.json`. Якщо версія нова, він завантажує файли, перевіряє їх і використовує з наступного запуску. Зіпсоване завантаження ніколи не замінить робочі матеріали.
- **Застосунок.** Кожна збірка з `main` публікується як GitHub Release (`Danskly.apk`). Встановлений APK показує на головному екрані «Доступна нова версія». Збірка для Google Play цього не робить, бо її оновлює сам Play.
- **Вебверсія** на сервері оновлюється з кожним деплоєм; офлайн-кеш працює за принципом «спершу мережа».

## Розгортання вручну (якщо потрібно)

```
node ../server/build.mjs   # з кореня репозиторію: node server/build.mjs
npx wrangler login
npx wrangler deploy
npx wrangler secret put OPENCODE_KEYS
```

### Ключі через панель Cloudflare (без термінала)

dash.cloudflare.com → Workers & Pages → **danskly** → Settings → **Variables and Secrets** → Add → Type: **Secret** → Name: `OPENCODE_KEYS` → Value: ключі через кому → Deploy.

Щоб додати чи прибрати ключ, просто зміни цей секрет. Перевидавати сайт не потрібно.

## Налаштування

Вони лежать у файлі `wrangler.jsonc`, розділ `vars`. Після зміни виконай `npx wrangler deploy`.

| Назва | Що означає | За замовчуванням |
|---|---|---|
| `AI_MODELS` | Моделі в порядку спроб, через кому | `deepseek-v4.1-flash,deepseek-v4-pro,glm-5.3-flash` |
| `AI_BASE_URL` | Адреса API OpenCode Go | `https://opencode.ai/inference/go/v1` |
| `AI_TIMEOUT_MS` | Скільки чекати одну спробу, мс | `20000` |
| `RATE_LIMIT` | Запитів до ШІ з однієї IP за 10 хвилин | `60` |

Секрети (лише через `wrangler secret put` або панель): `OPENCODE_KEYS`, `ACCESS_CODE`.

**Якщо перевірка пише, що модель недоступна, або видає помилку 404:** у документації OpenCode зустрічаються дві адреси API. Спробуй замінити `AI_BASE_URL` на `https://opencode.ai/zen/go/v1` і знову виконай `npx wrangler deploy`. Актуальний список моделей: `https://opencode.ai/inference/go/v1/models`.

## Як оновлювати застосунок

Коли я надсилаю новий `index.html`, поклади його в папку `public` і виконай:
```
npx wrangler deploy
```
Ключі й налаштування при цьому зберігаються.

## Телефон

Відкрий адресу сайту в Safari (iPhone) або Chrome (Android) і додай на головний екран. Тепер «Встановити» працює правильно: Danskly ставиться як окремий застосунок з червоною іконкою «d.» і відкривається на весь екран. Слова, граматика, завдання й читання працюють і без інтернету; ШІ потребує з'єднання.

## Скарги на відповіді ШІ

Застосунок Danskly для Android має кнопку «⚑ Поскаржитися на відповідь» (цього вимагає Google Play для застосунків із генеративним ШІ). Скарги надходять на `/api/report` і записуються в журнал воркера: **Cloudflare → Workers & Pages → danskly → Observability → Logs**, пошук `danskly-report`. Переглядай їх хоча б раз на тиждень і, якщо треба, уточнюй системну підказку в `src/worker.js`.

## Важливо про OpenCode Go

- **Ліміти підписки:** за 5 годин можна витратити до 20% місячного ліміту, за тиждень — до 50%. Якщо ліміт вичерпано, сервер переходить до інших ключів і моделей, а коли закінчиться все, користувач побачить «Усі ключі й моделі зараз недоступні».
- **Умови використання:** OpenCode описує Go як сервіс для OpenCode та інших агентів для програмування і стежить за трафіком на предмет зловживань. Застосунок, яким користуються багато людей, — інший сценарій, тож перед тим, як роздавати посилання широко, перевір умови OpenCode. Для публічного застосунку надійніше підходить звичайний платний API DeepSeek з оплатою за використання: сервер працюватиме з ним, якщо змінити `AI_BASE_URL` і `AI_MODELS`.
- Ключі від різних людей чи акаунтів збирати в один сервер не варто: це може порушити умови сервісу.

## Локальний запуск (для перевірки на комп'ютері)

Скопіюй `.dev.vars.example` як `.dev.vars`, впиши ключі й виконай `npx wrangler dev`. Застосунок відкриється на `http://localhost:8787`.
